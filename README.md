# Football Decision Lab

Helping coaching staffs make better decisions through data, AI and football knowledge.

## Mission

Football Decision Lab is an open project focused on transforming football event data into clear, actionable decisions for coaching staffs.

The project is based on three principles:

- Prioritize information
- Explain insights
- Support football decisions
